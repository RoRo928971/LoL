# LoL ビルドコンパニオン

リーグ・オブ・レジェンドの**アイテムビルド**と**ルーン構成**を手助けする非公式コンパニオンアプリです。
Riot Games 公式の静的データAPI [Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon) から
常に最新パッチのデータを日本語で取得します(APIキー不要)。

## 機能

- **チャンピオン一覧** — 全チャンピオンを名前検索・ロール(タンク/メイジ等)で絞り込み
- **ビルド推薦** — チャンピオンごとに以下を自動提案
  - ルーン構成(メインツリー・キーストーン・サブツリー・ステータスシャード)
  - アイテムビルド(スタートアイテム / ブーツ / コア3点 / 状況対応アイテム)と合計ゴールド
  - 「プレイスタイル」セレクタで型(ADC・メイジ・タンク…)を手動で切り替え可能
- **対面対策** — 対面チャンピオンを選ぶと脅威(物理/魔法/回復/バースト/高耐久)を分析し、
  自分のプレイスタイルに合った対策アイテム(物理防御・魔法防御・回復阻害・対タンク・生存)を提案
- **スキル上げの順番** — 定番チャンピオン約100体の推奨スキルオーダーを収録
  (未収録チャンピオンは「目安(自動推定)」と明示して表示。アフェリオス等の特殊型にも対応)
- **試合プラン** — 試合の味方5体・敵5体を設定すると自動で分析
  - チームバランス: 物理/魔法ダメージ比率、前衛・エンゲージ・ポーク・バースト・後半型の数、
    構成タイプ判定(エンゲージ/ポーク/ピック/ファイト/バランス)、味方構成の穴の警告
  - あなたのビルド: 敵チーム全体の脅威から対策アイテムを優先度順に算出。ブーツも敵構成で調整
  - 戦い方: 構成タイプの噛み合わせ・勝ち筋(スケーリング比較)・自分の役割・警戒すべき敵を提示
  - 入力は途中まででも動作し、ブラウザに保存される
- **コンボと使い方** — 定番チャンピオン約60体の標準コンボをスキルアイコン付きで収録。
  プレイスタイル別の「立ち回りの基本」、Riot公式の使い方ヒント(allytips)と対面時の注意(enemytips)も表示
- **マイデータ分析** — Riot ID を入力して自分の戦績を分析
  (勝率・KDA・CS/分・ビジョンスコア・チャンピオン別/ロール別成績・最近の試合・ランク情報)
- **アイテム図鑑** — 完成アイテムを名前・効果テキストで検索
- **ルーン図鑑** — 全ルーンツリーの一覧と効果説明
- **スキル表示** — 各チャンピオンのパッシブ + Q/W/E/R の説明

## 起動方法

依存パッケージなし (Node.js 18+ のみ) で動作します。

```bash
node server.js
```

ブラウザで `http://localhost:8000` を開いてください。
(チャンピオン等のデータはブラウザから直接 Data Dragon CDN へ取得するため、インターネット接続が必要です)

マイデータ機能を使わない場合は、静的サーバー (`python3 -m http.server 8000` 等) でも動作します。

### マイデータ (自分の戦績分析) の準備

1. [developer.riotgames.com](https://developer.riotgames.com) に Riot アカウントでログインし、
   開発用APIキー (`RGAPI-...`) を発行する。**開発用キーは24時間で失効**します(再発行は無料・即時)
2. アプリの「マイデータ」タブでキーを入力する(ブラウザに保存されます)。
   もしくは環境変数で起動: `RIOT_API_KEY=RGAPI-xxx node server.js`
3. Riot ID (例: `プレイヤー名#JP1`) とリージョンを入力して「分析する」

分析内容: 勝率 / KDA / CS毎分 / ビジョンスコアの平均、チャンピオン別・ロール別成績、
最近の試合一覧(勝敗・ビルド・キーストーン・キュー種別)、ソロ/フレックスのランク情報。

> Riot API はブラウザからの直接アクセスを許可していないため、`server.js` が
> APIキーを付与して中継します。キーが外部に出ることはありません(通信先は Riot API のみ)。
> 開発用キーのレート制限 (20req/秒・100req/2分) に収まるよう、並列数制限とキャッシュを実装しています。

## 仕組み

- `js/ddragon.js` — Data Dragon から最新バージョン・チャンピオン・アイテム・ルーンを取得(日本語 → 英語フォールバック)
- `js/archetypes.js` — 「アーキタイプ」(ADC・メイジ・アサシン等 9 種)の定義。ルーン優先リスト・アイテム採点の重み・定番アイテムの加点を持つ
- `js/recommend.js` — 推薦エンジン
  - ルーン: 優先IDリストを実データと突き合わせ、存在しないルーン(パッチで削除等)は自動でフォールバック
  - アイテム: タグ・ステータスへの重み付けで全完成アイテムを動的に採点し上位を提案。パッチでアイテムが追加・削除されても壊れない設計
- `js/matchup.js` — 対面対策エンジン。対面のタグ・評価値から脅威プロファイルを判定し、
  アーキタイプ別の対策アイテム(ID優先リスト + タグフォールバック)を提案
- `js/skillorder.js` — スキルオーダー収録データ(定番チャンピオン)+ 未収録時のフォールバック
- `js/combos.js` — コンボ収録データ(トークン表記: Q/W/E/R/AA=通常攻撃/FL=フラッシュ)と
  アーキタイプ別の立ち回りガイド。未収録チャンピオンは立ち回りガイドのみ表示
- `js/teamcomp.js` — チーム構成分析。ダメージ比率・前衛/エンゲージ等のカウント・構成タイプ判定、
  敵チーム全体からの統合脅威リスト生成、ブーツ調整、戦い方アドバイスの生成
- `js/mydata.js` — 戦績分析。Riot ID → puuid 解決、マッチ履歴取得、勝率/KDA/チャンピオン別集計
- `server.js` — 静的配信 + Riot API 中継サーバー。中継先パスのホワイトリスト、
  マッチ詳細の長期キャッシュ、429 (レート制限) の Retry-After 転送を実装
- `js/app.js` — UI とハッシュルーター(`#/champions`, `#/champion/:id`, `#/items`, `#/runes`, `#/mydata`)

チャンピオンの初期アーキタイプは Data Dragon のタグ(`Marksman` 等)と
攻撃/魔法/耐久の評価値から自動判定されます。
